## 🛠 Мой стек технологий и инструментов:
*   **Теория тестирования:** Виды и уровни, жизненный цикл бага, написание тест-кейсов, чек-листов и тест-планов.
*   **Тест-дизайн:** Классы эквивалентности, граничные значения, попарное тестирование (Pairwise).
*   **Инструменты:** 
    *   **DevTools:** Анализ сетевых запросов (Network), поиск ошибок в Console, манипуляция DOM.
    *   **Postman:** Построение коллекций, работа с Environment Variables, написание автотестов на JavaScript.
    *   **SQL:** Запросы с `JOIN`, `LEFT JOIN`, `GROUP BY`. Поиск аномалий и целостности данных.
*   **Архитектура:** Понимание клиент-серверной архитектуры, работа с HTTP-методами и статус-кодами.
